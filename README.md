# 철수선 · EXTRACTION LINE

선박을 탐사하며 파밍하고, 무기를 강화·진화시켜 생존하는 Godot 모바일 게임 프로토타입입니다.

## 실행

1. 저장소를 다운로드하거나 clone합니다.
2. Godot 4.6.3에서 `project.godot`를 가져옵니다.
3. F5로 실행합니다.

소스 프로젝트이며 APK는 포함하지 않습니다. 실제 결제는 연결되지 않았습니다.
