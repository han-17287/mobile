# 철수선 0.6 — 한 판 성장과 무기 진화

Godot 4.6.3 네이티브 모바일 게임 프로젝트입니다. APK가 아닌 소스 프로젝트이며,
`project.godot`를 Godot에서 가져온 뒤 F5로 실행합니다. 실제 결제는 없습니다.

## 한 판 성장
- 적을 잡아 경험치를 수집하면 전투가 멈추고 강화 3개 중 하나를 선택합니다.
- 일반 적 경험치 2, 정예 12. 다음 레벨 요구량은 6부터 레벨마다 3씩 증가합니다.
- 소총과 현재 보조무기 강화가 우선 제시됩니다. **무기 강화 IV + 지정 보조 능력 II**이면 진화가 확정 선택지로 나타납니다.
- 소총 보조 능력은 분산 사격, 보조무기는 광역 증폭입니다. 필요한 보조 능력도 강화 IV 이후 우선 제시됩니다.
- 선택마다 탄약 8발과 체력 8을 보충합니다. 추가 탄환을 발사해도 소총은 한 번 발사할 때 탄약 1발만 사용합니다.
- 이번 판 강화·진화는 철수/사망 후 새 탐사를 시작하면 초기화됩니다. 같은 탐사 이어하기에는 유지됩니다.
  기지의 영구 장비 승급과 별개이며 보석을 소비하지 않습니다.

| 무기 | 진화 | 주요 변화 |
| --- | --- | --- |
| 소총 | 탄막 폭풍 | 다중 탄환, 관통, 도탄, 대형 폭발 |
| 카타나 | 월광 난무 | 기본 공격마다 여러 방향 검기 |
| 망치 | 지진 분쇄기 | 넓은 타격과 전방 추가 충격파 |
| 방망이 | 메테오 홈런 | 콤보에서 폭발 야구공, 특수 공격 다중 발사 |
| 방패 | 철벽 행진 | 넓어진 공격과 3연타, 특수 공격 재사용 대기 감소 |

1·2구역마다 3웨이브가 차례로 몰려옵니다. 경험치 흡수 범위를 넓히고 연속 처치 표시와
범위 공격 효과를 추가했습니다. 적 120마리(보스 별도), 탄환 260개, 효과 180개로 제한합니다.
수치는 플레이테스트 전 초안입니다. 0.5 탐사를 이어가면 새 처치 목표가 적용되지만,
이미 시작한 보스전은 앞 구역 목표를 완료한 상태로 복원합니다.

## 챕터 진행
1. **CH.01 범선 검은 돛**: 처음부터 도전 가능.
2. **CH.02 호화 요트 오로라**: 1챕터 클리어 후 해금.
3. **CH.03 크루즈 메리디언**: 2챕터 클리어 후 해금.

각 챕터 목표는 **1구역 60처치 → 2구역 100처치 → 3구역 최종 보스 처치 → 마지막 철수 지점에서 귀환**입니다.
구역 목표는 해당 구역에서 처치해야 진행하며, 1구역 목표가 완료돼야 2구역 처치가 집계됩니다.
선수에 먼저 도착해도 앞 구역 목표를 달성하지 않았다면 보스가 나타나지 않습니다.
마지막 철수 지점은 전장과 해도에 FINAL/최종으로 표시되고, 보스 처치 후 화살표가 해당 지점을 안내합니다.

중간 철수는 가방 물품만 회수하며 챕터를 클리어하지 않습니다. 보스를 처치했어도 사망하거나
중간 철수 지점으로 돌아오면 다음 배가 열리지 않습니다. 클리어한 챕터는 반복 탐사 가능합니다.
잠금은 UI와 출격 로직 모두에서 검사합니다. 완료 기록은 로컬 저장되며 한 번에 다음 챕터 하나만 열립니다.

최종 보스는 챕터별 이름과 체력/피해가 다릅니다. 현재는 모두 추격·접촉 공격과
**1초간 지면을 표시한 뒤 반경 110의 범위 공격**이라는 공통 패턴을 사용합니다.
방패의 불도저 무적으로 범위 공격을 피할 수 있습니다. 보스 처치 후 추가 적 생성은 중단됩니다.
목표 수치, 보스 체력 2000/2700/3400, 공격 피해 25/30/35는 초기 테스트용 값입니다.
보스 등장/체력/공격 예고, 구역 처치 수, 보스 처치 여부는 탐사 저장에 포함됩니다.

0.4의 진행 중 탐사는 장착 장비·가방 장비·판매 물품·부품을 기지에 회수합니다.
이전 버전에는 챕터 완료 기록이 없으므로 새 진행은 1챕터부터 시작하고, 기존 기지 자산은 유지합니다.

## 선박 맵 업데이트
- **검은 돛 / 범선:** 나무 갑판, 돛대와 밧줄, 좌우 포대, 화물 더미, 해치, 조타륜, 선장실 지도 탁자.
- **오로라 / 호화 요트:** 선미 비치클럽, 수영장과 선베드, 헬리패드, 화분, 바, VIP 라운지.
- **메리디언 / 크루즈:** 탑승 홀과 리셉션, 피아노, 네 객실과 중앙 복도, 카지노, 브리지, 구명정.
- 세 맵 모두 배별 전투 장애물/통로/보관함/탄약/철수 지점이 다릅니다. 크루즈는 넓은 선체,
  범선은 선수의 긴 돛대 지지대와 나무 난간으로 외형도 구분했습니다.
- 바다 물결, 수영장 물결, 선체·난간, 가구 그림자, 갑판 판재를 엔진 도형으로 그립니다.
- 선체 경계와 가구·벽에 충돌하며 배 밖/수영장/침대/포대를 통과할 수 없습니다.
  적은 통로를 따라 우회 추격하고, 벽과 가구는 탄환 및 장비 범위 공격의 시야를 막습니다.
- 배마다 3개 보관함을 1.6초 동안 수색합니다. 멀어지면 취소, 피격 시 진행 초기화.
  한 번만 획득 가능하고 사용 여부를 저장합니다. 깊은 곳은 판매 물품·부품과 장비 확률이 증가합니다.
- 상단 **해도** 버튼: 탐사를 일시정지하고 선체 전체, 현재 위치, 철수 지점, 남은 보관함 확인.
- 기지의 **챕터 선택**에서 실제 갑판 축소도를 보고 배를 선택할 수 있습니다.

현재는 각 배의 공간을 한 층의 평면에 구성한 수작업 2D 맵입니다. 실제 층간 전환, 배 운항,
파괴 가능한 가구, 문 개폐, 실시간 그림자, 최종 텍스처 아트는 포함하지 않습니다.

## 무기와 장비
- 주무기 소총: 강한 자동 사격, 출격 탄약 48. 탄약이 없으면 보조무기로 자동 전환.
  맵의 보급 상자에서 24발, 일반 탄약 드롭에서 6발, 매 5처치째 드롭에서 12발 보충. 보충 후 총으로 직접 전환.
- 카타나: 빠른 3연속 베기, 마지막 타격 강화. 특수 공격은 다수 적을 관통하는 검기.
- 망치: 강한 한 방, 이동/공격 속도 느림. 차지 버튼 홀드 후 놓아 광역 강타.
  특수 휠윈드는 2.6초 회전 공격. 차지는 기본 공격 쿨다운 이후에 축적됩니다.
- 방망이: 낮은 피해와 강한 밀치기. 홈~런!은 강한 야구공 투사체.
- 방패: 두 번 타격, 들고 있는 동안 받는 피해 25% 감소·넉백 거리 30% 감소·이동 속도 감소.
  불도저!는 2초 무적/고속 돌진하며 맞은 적을 띄움. 피해 감소와 저항은 기본 등급부터 적용.
- 네 무기의 공격 모양과 손에 든 외형, 콤보/회전/투사체/차지 게이지가 다릅니다.
- 캐릭터를 다리·군화·방탄복·배낭·방독면·고글·주황색 식별표가 있는 도형 기반 대원으로 개편.
  완성된 일러스트/스프라이트 애니메이션은 아닙니다.

## 기본 조작
- 모바일: 왼쪽 전투 영역 드래그 이동, 오른쪽 무기 전환/특수/차지/회복 버튼.
  두 손가락으로 이동과 버튼 사용을 동시에 할 수 있습니다.
- PC: WASD/방향키 또는 마우스 드래그 이동, Q 무기 전환, Space 특수, F 홀드 차지, E 회복,
  I 가방, Esc 일시정지. 사거리 안에 적이 있으면 선택한 무기로 자동 기본 공격.
- 차지는 망치를 들 때만 보입니다. 특수 공격은 보조무기를 들 때만 사용.
- 창 포커스 상실/백그라운드 전환 시 정지하며, 미완성 차지는 취소됩니다.

## 탐사
기지에서 해금된 범선·호화 요트·크루즈 챕터를 선택합니다.
선미에서 승선해 중앙 갑판과 선수 방향으로 진입합니다. 배별로 좁은 통로와 우회 경로가 다릅니다.
깊은 구역일수록 적 체력·밀도, 판매용 물품 가치, 장비 드롭률과 상위 등급 비중이 증가합니다.

체크포인트는 각 구역에 하나씩 있습니다. 가까이 가면 `체크포인트 · 철수` 버튼이 나타납니다.
누른 뒤 3초간 머물면 귀환하며, 버튼을 누르지 않으면 계속 탐사할 수 있습니다.
피격 시 철수 진행이 초기화되고 구역 밖으로 나가면 요청이 취소됩니다.
이전 버전의 60초 대기 후 자동 탈출 방식은 제거했습니다.

## 아이템과 사망 규칙
- 장착 슬롯은 소총 1개, 보조무기 1개입니다.
- **사망 시 현재 장착 장비는 유지, 가방 속 모든 장비/물품/현장 부품은 손실됩니다.**
- 가방에서 장비를 장착하면 기존 장비가 가방으로 이동합니다. 사망하면 기존 장비가 사라집니다.
  예: A총으로 출발 → B총 획득/장착 → A총은 가방 → 사망 시 B총 유지, A총 손실.
- 기지 창고·보유 크레딧·보석·에너지·영구 방호 개량은 유지됩니다.
- 철수 시 가방 장비는 창고, 부품은 기지, 판매 물품은 보관됩니다.
  물품은 무기고에서 일괄 판매해야 크레딧으로 바뀝니다. 장비는 개별 판매 가능합니다.
- 일반 보조무기 네 종류를 바로 비교하도록 카타나는 장착, 나머지 세 종류는 초기 창고에 지급합니다.
- 현재 판매 물품은 개별 모양/슬롯 대신 총 판매 가치로 표시합니다. 가방 무게/칸 제한은 없습니다.

## 승급과 보급
- 무기고에서 창고 장비를 장착/판매/분해할 수 있습니다. 분해·판매는 확인창이 있습니다.
- 희귀 이상 장비를 분해하면 동일 등급 에너지 1개. 해당 에너지 1개로 바로 아래 등급의 장착 무기를 승급.
- 종류는 유지되고 피해가 증가합니다. 망치가 느린 것, 방망이의 밀치기 등 장단점은 유지됩니다.
- 임시 승급 단계: 일반 → 희귀 → 영웅 → 전설. 전설이 최대입니다. 일반 장비는 판매만 가능.
- 기지 장비 뽑기는 보석 100개 또는 뽑기권 1장. 초기 뽑기권 3장, 초기 보석 0개.
- 임시 확률: 일반 70% / 희귀 24% / 영웅 5% / 전설 1%. 등급과 별개로 5종 무기가 동일 확률.
  현재 천장/확정 누적 보상은 없습니다. 획득 장비는 기지 창고에 지급됩니다.
- 일반 적 장비 드롭률은 외곽 1% / 내부 2% / 심층 3.5%, 중장갑 적은 8%.
  조건부 등급 비율(일반/희귀/영웅/전설): 외곽 85/11/3.8/0.2%, 내부 65/25/9.4/0.6%, 심층 45/39/15/1%.
  모두 플레이테스트 전 임시 수치입니다.

보석 구매는 **무료 테스트 지급**입니다. 가격은 기획 예시이며 실제 청구되지 않습니다.
Google Play Billing/StoreKit, 영수증 검증, 서버 자원 원장, 환불 처리는 미구현입니다.
출시 전에 테스트 지급을 제거하고 정식 결제를 연결해야 합니다. 로컬 파일을 실제 유료 자원의 원장으로 사용하면 안 됩니다.

## 저장
전투 중 5초마다, 회복/일시정지/장비 교체/특수 발동/상자 수집/백그라운드/종료 시 로컬 저장.
탄약, 장착 장비, 가방, 보급 상자 사용 여부, 특수 쿨다운/지속 시간, 적·탄환·드롭·스킬 등을 복원합니다.
강제 종료 시 마지막 체크포인트 이후 최대 약 5초 진행은 손실될 수 있습니다.
0.3의 진행 중 육상 탐사는 장착 장비를 유지하고 가방 장비·판매 물품·부품을 기지로 회수한 뒤 종료합니다.
0.1/0.2 저장은 기존 규칙대로 기지 자산·방호 개량을 유지하며 새 장비 세트를 지급합니다.

## Android / iOS 빌드
APK/AAB는 포함하지 않습니다. 작업 환경에 Android SDK와 Godot 내보내기 템플릿이 없습니다.
1. Godot Editor > Manage Export Templates에서 4.6.3 템플릿 설치.
2. Godot 4.6 문서에 맞는 JDK/Android SDK 설치 후 Editor Settings > Export > Android에서 경로 지정.
3. Project > Export > Add > Android. 본인의 패키지 이름 지정 후 Debug APK 내보내기.
4. 출시 시 본인 서명키와 스토어 설정, AAB 내보내기 필요.
iOS는 macOS/Xcode, iOS 템플릿, Apple 서명이 필요합니다.
세로 방향/480×900 기준 화면 조정은 프로젝트에 설정돼 있습니다.
휴대폰 실기기 터치·성능·노치 safe area·실제 앱 수명주기는 아직 검증하지 않았습니다.

## 검증
Godot 4.6.3 headless에서 다음 테스트 통과:
- test_growth.gd: 웨이브 진행, 강화 선택, 진화 조건/확정 제시, 폭발·도탄, 보조무기 변화,
  탄약/경험치 수집, 같은 탐사 복원 및 새 탐사 초기화.
- test_weapons.gd: 탄약 소모/자동 전환/보충, 콤보, 차지/연속 악용 방지, 회전, 밀치기,
  투사체, 방패 2연타/피해 감소/넉백 저항/무적/띄우기, 저장, 장착-가방 사망 규칙.
- test_chapters.gd: 잠금 선택/출격 거부, 구역별 목표, 중간 철수/사망 시 미해금, 세 챕터 순차 클리어,
  보스 전투 복원·범위 공격·무적, 최종 철수, 중복 해금 방지, 재플레이 및 0.4 저장 마이그레이션.
- test_ship_ui.gd: 선박 선택→승선, 해도 일시정지/복귀, 벽 너머 아이템 흡수 방지.
- test_scroll.gd: 손가락 메뉴 스크롤과 드래그 시 장비 버튼 오작동 방지.
- test_touch.gd: GUI 이벤트로 두 손가락 이동+무기 전환+망치 홀드, 모달 뒤 버튼 차단, 확인창 터치.
- test_maps.gd: 세 배의 모든 보관함·탄약·철수 지점까지 실제 이동 검증, 선체/가구/탄환 충돌,
  적의 선수까지 우회 경로, 유효 갑판에만 적 생성, 수색 취소/중복 방지, 맵·보급·보관함 저장.
- test_state.gd: 보급 차감, 철수 중복 정산 방지, 사망 자산 보존, 판매/분해/승급/뽑기 비용, 저장 마이그레이션.
- test_ui.gd: 상점/전투/가방 연계, 복원, 철수 요청/취소/정산, 사망.
- test_survival.gd: 180초 전투 시뮬레이션. 테스트용 높은 체력 사용으로 난이도 검증은 아님.
일부 headless 전투 테스트 종료에서 Godot의 AudioStreamWAV/Playback 정리 경고가 발생했습니다.
게임 규칙 단언은 통과했으며 그래픽 미리보기 실행에서는 해당 경고가 나타나지 않았습니다.

- Linux OpenGL에서 무기 네 종류, 기지, 가방, 무기고, 보석 상점 렌더링 확인.

테스트는 저장을 만들고 지우므로 반드시 새 테스트용 데이터 폴더에서 실행하세요.
Linux 예:
```
test_data_dir=$(mktemp -d)
XDG_DATA_HOME="$test_data_dir" godot --headless --audio-driver Dummy --path . --script res://tests/test_weapons.gd
```
`tests/capture_ships.gd`(또는 capture_preview.gd)도 새 데이터 폴더에서 그래픽 디스플레이와 함께 실행하세요.
`previews/`는 실제 엔진 화면이지만 기능을 보여주도록 구성한 시연 장면입니다.
